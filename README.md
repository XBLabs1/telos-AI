# telos-AI
Open source platform for training robots using webcam teleoperation data. No expensive hardware or rigs required.

## What is Telos?
Telos is an open source platform that lets anyone train robot AI policies using webcam footage. Built on top of 
LeRobot, it uses Phantom Datasets — synthetic overlays of your robot arm — to generate clean training data locally 
on your own machine.
